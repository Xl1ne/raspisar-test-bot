# Расписарь

Сервис синхронизации расписания учебной группы. Раз в сутки забирает расписание из
источника, хранит его, отдаёт файл iCalendar по постоянной ссылке для подписки в Google
Calendar и Apple Calendar и доводит изменения до студентов через Telegram-бота. Староста
правит занятия вручную, и его правка приоритетнее данных источника.

## Состав

| Модуль | Назначение |
|---|---|
| `app/adapter.py` | Адаптер источника: забирает страницу, разбирает HTML, различает числитель и знаменатель. Единственный модуль, знающий форму источника |
| `app/timeutil.py` | Единственное место работы со временем: UTC ↔ Europe/Moscow, чётность недели, разворачивание шаблона в даты |
| `app/storage.py` | SQLite: группы, занятия, подписчики, объявления. Данные источника и ручные правки — раздельные строки |
| `app/ical.py`, `app/publication.py`, `app/api.py` | Служба публикации: файл iCalendar по ссылке с непредсказуемым кодом |
| `app/scheduler.py` | Суточный сбор; неудачный сбор не затирает прошлую версию |
| `app/bot.py` | Telegram-бот (aiogram 3), планировщик запускается внутри его процесса |
| `emulator/` | Эмулятор источника — статическая страница, повторяющая структуру реального расписания |

Стек: Python 3.11, aiogram 3, BeautifulSoup 4, icalendar, FastAPI + Uvicorn, SQLite.
Версии закреплены в `requirements.txt`.

## Запуск

Нужны Docker и Docker Compose. Скопируйте `.env.example` в `.env` и впишите токен бота.

```bash
docker compose up -d --build
```

Поднимаются три контейнера: `bot`, `api` (порт 8000) и `source` — эмулятор источника
(порт 8081, внутри сети доступен как `http://source/raspisanie.html`).

- Проверка живости: `http://localhost:8000/health`
- Календарь группы: `http://localhost:8000/calendar/<код>.ics`
- Логи бота: `docker compose logs -f bot`
- Остановить: `docker compose down`

Если путь к папке проекта содержит символы вне ASCII, сборка образов падает с ошибкой
`header key "x-docker-expose-session-sharedkey" contains value with non-printable ASCII
characters`. Обход: создать символическую ссылку с ASCII-именем на папку проекта и
выполнять команды Docker из неё.

Публичный доступ к календарю (для Google и Apple, которые забирают файл со своих серверов)
обеспечивается туннелем ngrok с постоянным адресом бесплатного тарифа:
`ngrok http 8000`.

## Настройки

Все значения читаются из переменных окружения, у каждой есть значение по умолчанию.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | токен Telegram-бота, обязателен |
| `RASPISAR_STUDY_START` | `2026-09-01` | первый учебный день; неделя с ним — числитель |
| `RASPISAR_SEMESTER_END` | `2026-12-27` | последний учебный день, горизонт расписания |
| `RASPISAR_COLLECT_HOUR` | `3` | час суточного сбора по московскому времени |
| `RASPISAR_FETCH_TIMEOUT` | `15` | таймаут запроса к источнику, секунд |
| `RASPISAR_TZ` | `Europe/Moscow` | часовой пояс отображения |
| `RASPISAR_DB` | `data/raspisar.db` | путь к файлу базы |

Расписание звонков (пара → время) задано в `app/config.py`.

## Тесты

```bash
docker compose run --rm --no-deps api pytest -q
```

Фикстуры страниц источника лежат только в `tests/fixtures/`. Два сторожевых теста
следят за границами: библиотека разбора HTML встречается ровно в одном модуле, работа с
часовым поясом — ровно в одном.

## Эмулятор источника

`emulator/raspisanie.html` воспроизводит структуру реальной публикации расписания: шесть
групп колонками, дни недели, пары римскими цифрами, числитель и знаменатель в одной
ячейке через пунктир, потоки с префиксом `П:код/`, пропущенные аудитории. Страница
намеренно неудобна для разбора, чтобы адаптер проверялся на данных, похожих на настоящие.
Целевая группа — `ОБ-09.03.03.02-41`, пятая колонка. Замена эмулятора на реальный
источник затрагивает только адрес источника у группы.
